# Boss Match Helper 使用说明

目标流程（快）：**按条件筛选 → 翻页采集列表 → 批量匹配出结果列表 → 你点看 → 再说自动打招呼**。

不再逐个点开职位慢慢分析。

## 安装

1. Chrome 打开 `chrome://extensions`
2. 开启「开发者模式」
3. 「加载已解压的扩展程序」→ 选择仓库根目录 `resumeposter`
4. 改代码后：先刷新扩展，再**刷新 Boss 页面**

## 配置（插件弹窗）

1. DeepSeek API 地址 / Key
2. 投递条件描述、排除关键词、匹配阈值
3. 上传简历（`.docx` / `.txt` / `.md`）或粘贴文本（自动保存）
4. 建议点「生成简历摘要」，再点 **「根据简历生成关键词」**（也可留空，采集时自动生成）

## 使用（Boss 职位页右下角面板）

1. **只筛选**：按弹窗条件跳转/点选 Boss 筛选项  
2. **采集并匹配**（主按钮）  
   - 可勾选「开始前先按投递条件筛选」  
   - 按多个关键词依次搜索；每个词慢速滚动加载（Boss 左侧列表通常不独立滚动，实际是**滚页面带动左侧**，禁止滚右侧 sticky 详情）  

   - 抓列表卡片信息后批量打分  
   - 面板显示待招呼/已招呼统计；详情点 **匹配记录** / **投递结果**  
3. **自动打招呼**：只对未招呼的「建议投」自动点 Boss「立即沟通」，带每日上限与间隔；可随时停止

## 为什么比以前快

| 以前 | 现在 |
|---|---|
| 每个岗位点开 → 等 JD → 调一次模型 | 先整页采集，再 8 条一批打分 |
| 边扫边停 | 先出完整结果列表，再决定是否自动投 |

说明：列表匹配主要用标题/公司/标签等卡片信息，速度优先；点进结果可再人工看完整 JD。

## 常见问题

- `Extension context invalidated` / 连接断开：刷新扩展后必须再刷新 Boss 页  
- 没结果：确认已登录、在职位列表页、弹窗条件/简历/Key 已保存  
- 自动打招呼失败：可能未登录、按钮是「继续沟通」、或风控弹窗
